## 四、常见问答

**Q：我改了口径，哪些文档的旧数字会过期？**
A：`61 §六`、`57 §0.0`、`58`、`32` 这四份需要同步。`33/34/41/50/54/55/56/59/60` 是历史快照，**不改**。

**Q：文档里说"旧值作废"是不是整篇都不能看了？**
A：不是。那是文档**内部**的新旧对照（如 `57` 用 11-15 实跑替换旧值），恰恰是复盘材料。只有第二节列的 9 份是整篇快照。

**Q：能不能把 57 的 md 和 html 合并？**
A：不能。html 是给答辩/复习看的交付件，md 是源。合并会丢掉一种格式。

**Q：能不能删掉 `eval/report_20261115_*.md` 那几份？**
A：不建议。每份对应一次真实复测（C18/C6/caliber/trust），是回归证据链，体积极小。
